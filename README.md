Allows controlling when HDR will turn on. Enables HDR only when certain application run in the background.

The purpose of the tool is to disable the need to manually enable / disable HDR before and after playing games. 
Simple configuration allows stating which applications require HDR when launching.
Automatically shows up in system tray after launching.

<img width="459" height="484" alt="image" src="https://github.com/user-attachments/assets/ed84df30-b364-430c-b1c4-da339d1a9315" />

- Type in a new application. No need to add the extension. Click Add and HDR will turn on when the app is detected.

> Removing Games :(

<img width="444" height="466" alt="image" src="https://github.com/user-attachments/assets/3ede3819-72d9-48c3-97ad-c81fcdf0b31a" />

- Click an application to remove and press the "Remove Selected" button. 

> Important!
Disables the ability to turn HDR on or off via the windows settings. Whenever the app is running, HDR will automatically turn off when trying to turn on manually.


> Multiple Programs Running
When multiple listed programs run in the background, HDR will not turn off until all the applications have been closed.  


> Apps Save Location
C:\Users\"User"\AppData\Local\HDRManager\apps.json
